# Tirta Gambut

Website statis multi-page untuk Laporan Praktikum 1 Desain Web (HTML5 Fundamentals dan Semantic Form).

Tirta Gambut adalah konsep sistem peringatan dini dan pembasahan otomatis lahan gambut. Website ini menjelaskan cara kerja sistem, menampilkan contoh data titik pantau, dan menyediakan formulir laporan warga. Seluruh data bersifat simulasi.

## Daftar Halaman

| File | Isi |
| --- | --- |
| `index.html` | Beranda: masalah kebakaran gambut, solusi, ringkasan status |
| `sistem.html` | Cara kerja sistem, komponen, tabel empat status risiko |
| `pemantauan.html` | Tabel data titik pantau, istilah, catatan |
| `lapor.html` | Formulir laporan warga dengan validasi HTML5 |
| `terima-kasih.html` | Halaman konfirmasi setelah formulir dikirim |

## Cara Membuka

1. Unduh atau clone repository ini.
2. Buka `index.html` di browser.
3. Gunakan menu navigasi untuk berpindah halaman.

Website ini murni HTML tanpa CSS dan JavaScript, sesuai ketentuan praktikum.
